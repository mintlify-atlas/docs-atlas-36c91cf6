BeautySalon is an open-source web application that digitalizes the day-to-day operations of a beauty salon. Salon owners and staff get a centralized admin panel to manage appointments, a rich service catalog, real-time staff availability, and a client history — while clients can book appointments online in minutes.

## Getting started

<Steps>
  <Step title="Try the demo">
    Visit [beautysalonsaas.netlify.app](https://beautysalonsaas.netlify.app) and click **Enter Demo** — no sign-up needed. See [Demo Mode](/demo-mode) for details.
  </Step>
  <Step title="Clone and configure">
    Fork the repository, create a Supabase project, and add your credentials to `.env`. See [Self-Hosting Setup](/self-hosting/setup).
  </Step>
  <Step title="Run migrations">
    Apply the included SQL migrations to create all tables and Row-Level Security policies. See [Database Setup](/self-hosting/database).
  </Step>
  <Step title="Log in and manage">
    Sign up for your admin account, then start adding services, staff, and categories before taking your first booking.
  </Step>
</Steps>

<Note>
  BeautySalon uses [Supabase](https://supabase.com) for authentication, database, and Row-Level Security. You need a free Supabase project to self-host the application.
</Note>
